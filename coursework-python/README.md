# Coursework Portfolio

A collection of programming exercises and course projects.

## Python Exercises

Small Python programs covering basic programming concepts:

- `helloworld.py` — print a first message
- `calculator.py` — simple calculator
- `time.py`, `clock.py` — time-related exercises
- `triangle_area.py` — calculate a triangle's area
- `tempereture.py` — temperature conversion exercise (original filename retained)
- `capacity.py` — capacity conversion exercise
- `round.py`, `round_part2.py` — rounding exercises
- `boolean.py`, `boolean_part2.py` — Boolean logic exercises
- `split.py`, `split_part2.py`, `join.py` — string split and join exercises
- `vowel.py` — vowel exercise
- `alnum.py` — alphanumeric check
- `palindrome.py` — palindrome check

### Run a program

Install Python 3, open a terminal in the `Python-Exercises` folder, then run a file, for example:

```bash
python helloworld.py
```

On some Windows installations, use `py` instead:

```cmd
py helloworld.py
```
