# Coursework_python
# Python Exercises

A collection of Python exercises for practicing fundamental programming concepts.
(รวมแบบฝึกหัดและโปรเจกต์บางส่วนของ Python)

## Exercises

| File | Description |
|---|---|
| `helloworld.py` | Print a simple message |
| `calculator.py` | Perform basic calculations |
| `time.py` | Practice working with time |
| `clock.py` | Practice clock-related concepts |
| `triangle_area.py` | Calculate the area of a triangle |
| `tempereture.py` | Practice temperature conversion |
| `capacity.py` | Practice capacity conversion |
| `round.py` | Practice rounding numbers |
| `round_part2.py` | Additional rounding exercises |
| `boolean.py` | Practice Boolean values and conditions |
| `boolean_part2.py` | Additional Boolean exercises |
| `split.py` | Split a string into parts |
| `split_part2.py` | Additional string-splitting exercises |
| `join.py` | Join strings together |
| `vowel.py` | Practice checking vowels |
| `alnum.py` | Check whether text contains letters and numbers |
| `palindrome.py` | Check whether text is a palindrome |
